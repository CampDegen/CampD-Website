# Outbound agent handoffs

Archive of briefings **sent to agents on other repos** (or pasted into their chat). Append-only: add a new file per handoff; do not rewrite delivered handoffs unless correcting a factual error.

## Filename

`YYYY-MM-DD-short-topic.md`

## When to add

- Website agent needs another repo’s agent to do work (e.g. CampD-SPT-Pack).
- Copy the file into that project or paste into that agent’s session.
- Add a short pointer in [notes/](../notes/) if useful; do not duplicate the full handoff there.
