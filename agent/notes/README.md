# Session notes

Append-only log. **Add a new file; do not edit prior notes** unless fixing a typo you introduced.

## Filename

`YYYY-MM-DD-short-topic.md`

## Template

```markdown
# Title (same as topic)

- **Date:** YYYY-MM-DD
- **Agent context:** (optional: local / cloud, branch)
- **Outcome:** done | blocked | superseded

## Summary

One short paragraph.

## Decisions

- Bullet facts future agents must know.

## Follow-ups

- [ ] Optional tasks left for humans or later agents.
```

## Index (optional)

Agents may skim filenames in sort order; no central index required.
